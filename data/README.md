# Data folder

Drop your product/company documentation here as `.pdf` or `.md` files.

Good sources if you don't have your own handbook handy:
- A public API's docs (e.g. Stripe, Twilio, Notion — save key pages as .md)
- An open-source project's user guide
- Your own resume/notes/project docs (also works for a personal-knowledge-base demo)

Then run `python src/ingest.py` to build the index.
